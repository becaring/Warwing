# Warwing

Warwing runs Super Smash Bros. for Nintendo 64 on Xbox 360 through
[BattleShip](https://github.com/JRickey/BattleShip) and
[Shipyard](https://github.com/becaring/Shipyard). The executable is `Smash360.xex`.
You supply a supported US ROM and the Xbox 360 SDK; this repository contains
neither game data nor SDK files.

Four controller slots work. Back/View toggles the enhancement menu. The right
stick moves the cursor, A clicks or drags, B right-clicks, LT/RT scroll, and R3
switches between cursor and D-pad navigation. Game mappings are set in the
port's controller menu. Native keyboard input, Raphnet USB transport, and
desktop postprocessing are unsupported.

See [Building](docs/BUILDING.md), [Assets](docs/ASSETS.md),
[Architecture](docs/ARCHITECTURE.md), and [Upstream](docs/UPSTREAM.md).
