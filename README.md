# Warwing

Warwing brings Super Smash Bros. for Nintendo 64 to Xbox 360 through
[BattleShip](https://github.com/JRickey/BattleShip) and
[Shipyard](https://github.com/becaring/Shipyard). The executable is `Smash360.xex`.
Supply your own supported US ROM and Xbox 360 SDK; game data and SDK files are
not included.

Four controller slots are supported. Back/View toggles the enhancement menu,
the right stick moves the cursor, A clicks or drags, B right-clicks, LT/RT scroll,
and R3 switches between cursor and D-pad navigation. Game mappings are configured
in the port's controller menu. Native keyboard input, Raphnet USB transport, and
desktop postprocessing are unsupported.

See [Building](docs/BUILDING.md), [Assets](docs/ASSETS.md),
[Architecture](docs/ARCHITECTURE.md), and [Upstream](docs/UPSTREAM.md).
